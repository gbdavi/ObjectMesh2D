# ObjectMesh2D

ObjectMesh2D é uma engine 2D simples, desenvolvida em JavaScript, com o objetivo de facilitar a criação de jogos e aplicações gráficas interativas. A engine oferece funcionalidades básicas para manipulação de elementos gráficos, como desenhos de formas geométricas e agrupamento de objetos, física para movimentação de objetos e detecção de colisões, gerenciamento de rotinas e gerenciamento de audio.

O projeto é uma continuação da engine utilizada no jogo [AMazeRelic](https://github.com/gbdavi/AMazeRelic) (desenvolvido por mim), aprimorando recursos e permitindo maior controle sobre os elementos gráficos.

## Funcionalidades

- **Manipulação de Canvas**: Manipule o <canvas> do HTML através de objetos.
- **Objetos Gráficos (Shape)**: Crie e desenhe formas básicas, como retângulos e círculos.
- **Agrupamento de Objetos**: Agrupe múltiplos objetos gráficos usando a classe ComplexObject.
- **Gerenciamento de Frames**: A classe Engine gerencia o framerate automaticamente.
- **Detecção de Colisões**: Sistema simples de verificação de colisões entre formas geométricas.
- **Eventos**: Geração de eventos simples para interações.
